# Project overview

FraudShiftBench treats evaluation conditions as typed deployment contracts.
Contracts describe temporal ordering, graph visibility, feature availability,
label access, checkpoint selection, review budgets, and resource envelopes.
Results are interpreted only inside the contract and evidence scope that
generated them.

The benchmark's primary contribution is an executable claim/evidence discipline
for temporal graph fraud evaluation. Its completed TKDE study shows that
strict-versus-isolated graph visibility and related construction choices can
change model rankings and thresholded decisions in the evaluated grid.

GraphSafe-TTA is retained as a secondary, bounded saved-score case. It is useful
for demonstrating claim discipline, negative comparisons, and decision-level
tradeoffs. It is not validated as a universal graph-learning method.

The public repository is a curated source and aggregate-evidence artifact. Raw
data, raw predictions, checkpoints, provider workspaces, and historical
archives are not distributed.
