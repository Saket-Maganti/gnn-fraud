\section{Problem formulation}

Let a deployment contract be
\[
c=(c^{\mathrm{time}},c^{\mathrm{vis}},c^{\mathrm{build}},c^{\mathrm{select}},c^{\mathrm{budget}},c^{\mathrm{resource}}).
\]
An axis may contain a category or continuous value together with observation state and confidence. Missing values receive an explicit mask; unseen categories map to an unknown token; out-of-range continuous values are identified relative to source-only normalization. An unseen \emph{combination} contains axis values observed separately in source contracts but not their joint tuple. An unseen \emph{value} was absent from all source contracts and is a distinct, harder regime.

Let \(\experts=\{1,\ldots,E\}\) be heterogeneous experts. Contract \(c\) induces an admissible graph view \(G_c\), prediction unit, label-access policy, review policy, and feasible set \(\feasible(c)\subseteq\experts\). Expert \(e\) emits score \(s_e(x;G_c)\), label-free diagnostic vector \(d_e(x,c)\), and a resource record. A router emits
\[
\pi_\theta(e\mid x,c,d)\geq 0,\qquad
\sum_{e\in\feasible(c)}\pi_\theta(e\mid x,c,d)=1,
\]
with zero mass outside \(\feasible(c)\). If the feasible set is empty, the policy emits an explicit abstention or a declared non-expert fallback rather than a spurious distribution.

For bounded loss \(\ell\), contract risk is
\[
R_c(\pi)=\mathbb E_{(X,Y)\sim P_c}\!\left[\ell\!\left(\sum_e\pi_\theta(e\mid X,c,d)s_e(X;G_c),Y\right)\right].
\]
For the V5 evaluation, let \(a_i\) indicate acceptance and let \(c_{\mathrm{abs}}\) be the frozen abstention cost. The matched offline oracle loss is
\[
L_i^\star=\min\!\left\{c_{\mathrm{abs}},\min_{e\in\feasible_i}(Y_i-s_e(X_i;G_c))^2\right\}.
\]
Method loss is \(c_{\mathrm{abs}}\) on abstained rows and squared error otherwise. The primary estimand is
\(\operatorname{Reg}^{\mathrm{row}}_c=|c|^{-1}\sum_i(L_i-L_i^\star)\), named \texttt{contract\_regret\_vs\_feasible\_row\_oracle}. It is nonnegative up to a frozen numerical tolerance because the oracle has the same feasible expert-or-abstain action space. A best fixed feasible non-abstaining expert over the whole contract is reported only as a separately named diagnostic.

Coverage is \(P_c(a_\theta=1)\), and selective risk is \(\mathbb E_c[\ell\mid a_\theta=1]\). It is undefined at zero coverage and is distinct from global target AUPRC. Review budget \(B_c\) may specify a fraction, fixed \(K\), cost matrix, or latency allowance. Resource constraints are applied before selection, while review budgets govern ranked action or abstention.

We evaluate seen contracts, unseen combinations, unseen values, partially observed and noisy contracts, dynamic resources, all-expert failure, and all-expert unavailability. Domain generalisation, unlabeled target adaptation, and few-label adaptation are separate access regimes. Target labels are unavailable for training, router selection, calibration, and threshold choice in the headline regime.
