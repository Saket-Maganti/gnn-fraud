\title{When Graph Structure Becomes a Liability:\\
  A Critical Re-Evaluation of Graph Neural Networks for\\
  Bitcoin Fraud Detection under Temporal Distribution Shift}

\author{Saket Maganti}
\date{}

\begin{abstract}
Graph Neural Networks (GNNs) are the de facto architecture for fraud
detection on transaction graphs, and published results on the Elliptic
Bitcoin Dataset consistently report GCN, GraphSAGE, GAT, and EvolveGCN
as state of the art.  We show that this consensus is an artefact of
the evaluation protocol rather than a property of graph learning.
Every prior Elliptic study uses \emph{transductive} evaluation, which
leaks test-period structure into training, and reports only aggregate
metrics over a 15-step test window that conceals a near-total failure
after step 42.  We re-run GCN, GraphSAGE, and GAT under strictly
inductive evaluation with multi-seed validation and per-timestep
reporting, and the picture inverts.  A plain three-layer MLP (F1~=
~0.744) beats every GNN we tested (best: GraphSAGE, F1~=~0.697), and
Random Forest with no graph structure reaches F1~=~0.820.  The cause
is temporal distribution shift: the fraud base rate drops
$39\times$ between training and the worst test steps, collapsing all
models from F1~$\approx$~0.78 to F1~$<$~0.03.  A multi-seed ablation
exposes an even sharper finding: \emph{randomly shuffling} the
transaction edges \emph{improves} GraphSAGE from F1~=~0.268 to
F1~=~0.383, so the real Bitcoin graph is not merely uninformative, it
is actively harmful.  Temperature scaling yields $\Delta$F1~=~0,
ruling out calibration as a remedy.  We then show the constructive
counterpart: a concatenation hybrid that feeds GNN embeddings and raw
features into a downstream Random Forest recovers F1~=~0.807,
exceeding every prior published result despite our stricter protocol.
Graph-derived representations carry complementary signal, but only
when a downstream classifier can selectively weight them against
tabular features.  We release code, checkpoints, and all experimental
scripts so the corrected protocol is reproducible.
\end{abstract}
