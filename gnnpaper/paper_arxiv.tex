\begin{abstract}
\noindent
Graph Neural Networks (GNNs) are widely assumed to outperform
feature-only baselines on financial fraud detection because transaction
graphs encode structural signals that isolated node features cannot
capture. This paper tests that assumption under a stricter experimental
protocol than prior work on the Elliptic Bitcoin Dataset, and finds
the opposite.

We benchmark GCN, GraphSAGE, GAT, and an MLP baseline across three
class-imbalance strategies on Elliptic (203,769 nodes, 234,355 edges,
49 temporal steps), using inductive mini-batch evaluation and
three-seed statistical validation. A Random Forest baseline under the
same protocol achieves F1\,=\,0.674. A plain three-layer MLP reaches
F1\,=\,0.744\,$\pm$\,0.005 and outperforms every tested GNN.
GraphSAGE, the strongest graph model, reaches only
F1\,=\,0.697\,$\pm$\,0.009. All results use inductive evaluation;
prior published results use transductive evaluation, which leaks
test-period graph topology into training.

The explanation is temporal distribution shift. The illicit rate
falls from 11.6\,\% during training to 0.3\,\% in the hardest test
steps; all models collapse after step~42, dropping from
F1\,$\approx$\,0.95 to F1\,$<$\,0.02. Random Forest feature
importance shows 82.4\,\% of discriminative power comes from local
transaction features, and the graph structure GNNs additionally learn
becomes misleading once the fraud distribution shifts. Temperature
scaling leaves F1 unchanged ($\Delta$F1\,=\,0), ruling out
calibration as a fix. An EvolveGCN CPU ablation (F1\,=\,0.29 versus
published GPU F1\,=\,0.77) quantifies the hardware dependency of
temporal graph models. Business-cost analysis shows the highest-F1
model is not always the cheapest to deploy under asymmetric error
penalties.

\textbf{Keywords:} GNN, fraud detection, temporal distribution shift,
Elliptic Bitcoin Dataset, class imbalance, concept drift, inductive
evaluation, ablation study.
\end{abstract}
